《靈境守衛》Alpha 0.1 — iPad / iPhone 試玩包

這是從現有 v2.5 原型整理出的 iOS Safari / PWA 試玩版，不是商業完成版。

如何發布：
1. 打開你的 GitHub 專案 -spirit-guardian。
2. 在儲存庫根目錄上傳這個資料夾內的全部檔案（不是直接上傳 ZIP）。
3. 確認 GitHub Pages 設定為 main 分支 /root。
4. 用 Safari 開啟 GitHub Pages 網址。
5. 點「分享」→「加入主畫面」。

如果 GitHub Pages 原本有其他 index.html，請先備份再覆蓋。
如果要保留舊遊戲，可改上傳至 alpha 資料夾，網址末端加 /alpha/。

本次可驗證新增：Safari 主畫面安裝資訊、manifest、圖示、離線快取、觸控安全區與響應式排版。
既有戰鬥、技能、存檔邏輯沿用 v2.5，尚未宣稱完成商業美術或完整系統。
注意：直接在 iPad「檔案」App 開啟 HTML，PWA 離線快取可能無法使用；必須透過 HTTPS 網址。
